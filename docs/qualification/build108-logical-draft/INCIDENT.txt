ROOT CAUSE PROVEN OFFLINE
The generation/lookup reader resolves raw certificate.id; storage/save resolves
LogicalConversationId.certified(certificate.id).value. These are different keys.
Legitimate previous consumption increments the serialized canonical draft key.
The next freeze reads raw generation 0 and compares canonical generation 1,
returning null before controller.send or queue/operation creation. Source-extracted
baseline fixture reproduces the exact popup predicate with zero transport calls.
The same namespace mismatch makes saved drafts unreadable to their own loader
and creates new action IDs on equivalent republication. Clear omitted actionId,
allowing an old same-content draft to clear a different replacement identity.

CORRECTION CONTRACT
Draft-only storage resolver uses one canonical application generation/preview key.
Read canonical and raw legacy slots; preserve serialized logicalId and actionId.
Keep occupied slots in place; equivalent dual slots remain equivalent. Conflicting,
foreign or malformed slots block without overwrite. General certificate/provider
resolver and routing doctrine remain unchanged. Rearm cannot resurrect absent or
replaced identity. Clear requires actionId, content and authority equality.
One tap carries one live same-owner guard through the queue to the last synchronous
boundary immediately before Dio.post. No await separates validation and invocation.
Real content, attachment selection, owner, identity or authority changes pause.
First HTTP API invocation commits the frozen batch; later edits are a new draft
and survive completion. API invocation is not proof of physical Apple execution.
Blocked unstarted batches settle all futures and reservations. Cleanup failure
retains replay evidence and blocks; foreign operations remain untouched.
Async restore cannot overwrite newer human edits or a disposed owner. Empty
logical attachments cannot import a physical-member attachment draft.
